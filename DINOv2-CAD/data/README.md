# ML-NDT data

The dataset is not redistributed in this repository.

Place the ML-NDT dataset here with the following layout:

```text
data/ML-NDT/data/
├── training/*.bins, *.labels
└── validation/*.bins, *.labels
```

The dataset is described in Virkkunen, Koskinen, Jessen-Juhler and
Rinta-Aho, "Augmented Ultrasonic Data for Machine Learning," *Journal of
Nondestructive Evaluation*, vol. 40, no. 1, 2021,
<https://doi.org/10.1007/s10921-020-00739-5>.
